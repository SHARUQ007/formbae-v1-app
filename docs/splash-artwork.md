# Splash artwork

The native iOS launch screen and React Native startup screen share a locally bundled 1024 × 1536 abstract mosaic. The original FormBae runner logo and live wordmark sit separately above the art. There are no people in the artwork. Aspect-fit rendering preserves the composition on different screen sizes; startup routing and preloading deadlines are unchanged.

Generated with the built-in image generation tool. JPEG packaging uses quality 82 (114,755 bytes), replacing the former 160,503-byte startup photo. iOS includes an identical copy in `SplashMosaic.imageset` for launch before JavaScript starts. Android displays its system launch icon before the React Native artwork.

Asset: `src/assets/editorial/startup-abstract-mosaic-v1.jpg`
